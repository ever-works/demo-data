# About this demo

This is the **Ever Works demo directory** — a live, public showcase of what a
directory built on the [Ever Works](https://ever.works) platform looks like.

## Everything here is fictional

Every listing in this directory is invented for demonstration purposes. The
products, companies and descriptions do **not** exist and are not reviews of,
or claims about, any real product or organisation.

## What you can try

- Browse by **category** or **tag**
- Use the **search**
- Open any listing to see a full detail page
- Look at **Pricing** to see the plan tiers a directory can offer
- Create an account and try the **submission** flow

Payments on this demo run against Stripe **test** keys, so nothing can be
charged. Use Stripe's published test cards if you want to walk through checkout.
